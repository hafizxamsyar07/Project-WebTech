About SmartBookStore

SmartBookStore is a simple web-based bookstore system developed for educational purposes. This project demonstrates basic e-commerce functionality such as browsing books, adding items to cart, and managing a wishlist.

The main goal of this system is to provide a smooth user experience while practicing frontend development skills using HTML, CSS, and JavaScript.

Features

  • Browse books collection
  • Search books
  • Add to cart system
  • Wishlist feature
